# Template head

`head.glb`, `albedo.jpg`, `normal.jpg` — "Lee Perry-Smith" head scan by
[Infinite-Realities](https://www.ir-ltd.net/), licensed under
[Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).
Redistributed via the three.js examples repository.

TwinMe uses this scan only as the *template topology* for the on-device
Instant Twin: it is non-rigidly warped to the user's face landmarks and
re-textured from the user's own photos. The demo avatar on the landing page
renders the original scan.
